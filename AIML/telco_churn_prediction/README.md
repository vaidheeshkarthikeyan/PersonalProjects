# Customer Churn Prediction Model

An end-to-end ML pipeline predicting telecom customer churn, with a focus on 
handling class imbalance and business-aligned evaluation.

## Project Structure
telco-churn-prediction/
├── data/           # raw and processed datasets
├── notebooks/      # exploratory analysis
├── src/            # source code (data prep, training, evaluation)
├── models/         # saved model artifacts
├── reports/        # figures and outputs
├── tests/          # unit tests
