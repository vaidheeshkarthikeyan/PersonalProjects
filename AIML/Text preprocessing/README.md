**Text Preprocessing using Natural Language Processing(NLP)**

In this Project, 'tripadvisor_hotel_reviews.csv' dataset is used. This dataset contains hotel reviews and ratings from which the reviews are taken and preprocessed
to make sure the dataset is clean.

**Techniques used**

>> Lowercasing
>> Removing Stopwords
>> Removing Punctuations
>> Tokenizing the text
>> Stemming the tokens
>> Lemmatizing the tokens
>> Analyzing n-grams
